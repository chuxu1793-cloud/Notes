## 1. 走样与 TAA 的基本思想

### 1.1 走样的频域本质

渲染是对连续二维图像信号 $I(\mathbf{x})$ 的离散采样。**Nyquist–Shannon 采样定理**：采样率至少达到信号最高频率的 2 倍，才能无混叠地重建原信号。而光栅化场景天然含有接近无限带宽的成分：几何硬边（阶跃信号，其频谱无限延伸）、细于一个像素的线条、高光点、高频纹理。像素网格的采样密度为每像素 1 个样本，可正确表示的最高频率为 0.5 周期/像素（奈奎斯特频率）；更高频率的成分在采样后**折叠混叠到低于奈奎斯特频率的频段**——表现为锯齿、边缘闪烁（shimmer）、摩尔纹，以及高光点在帧间的出现与消失。

### 1.2 空间抗锯齿的谱系与 TAA 的位置

| 方案 | 思想 | 缺点 |
|---|---|---|
| SSAA | 以 $N\times$ 分辨率渲染后降采样（真实超采样） | 成本为 $N$ 倍 |
| MSAA | 只对几何覆盖率/深度多采样，每像素着色一次 | 只消除几何边缘走样，不处理着色走样（纹理与高光的闪烁）；deferred 与后处理管线下代价高 |
| 后处理 AA（FXAA/SMAA 形态学） | 对已走样的图像做启发式边缘重建 | 混叠已经发生，无法恢复被折叠破坏的信息 |
| **TAA** | 将 $N$ 个采样点**分布于 $N$ 帧的时间轴上**累积 | 引入时序伪影：鬼影/闪烁/模糊（见 §1.3） |

TAA 的核心思想：**每帧将整个采样网格偏移一个亚像素距离（抖动）→ 用运动矢量将历史样本重投影对齐到当前帧 → 与当前帧按权重混合**。在重投影与混合理想的前提下，完全静止的像素经 $N$ 帧累积后等效于 $N$ 点超采样——即以时间换取空间采样率。

三个关键机制的分工（缺一不可）：

```
抖动 jₙ ──► 光栅化（抖动投影）──► 当前帧 Cₙ、深度 Dₙ
                                      │
        相机/对象 MV（无抖动 VP 对）──► 速度 Vₙ
                                      │
历史 Hₙ₋₁ ─(uv + Vₙ 重投影)─► 邻域裁剪 ─► 混合 ─► Hₙ（乒乓写入）─► 输出
```

- **没有抖动**：静止画面的样本位置逐帧相同，累积不产生新的采样信息——静止内容保持原有走样，运动内容则因重投影与混合产生运动模糊，超采样收益无从建立；
- **没有重投影**：历史按当前 uv 直接采样，抖动相位与几何运动均未对齐，画面严重模糊；
- **没有裁剪**：历史中已失效的样本（遮挡变化、出屏后采样到其它表面）继续被累积到输出中，形成鬼影。

### 1.3 三大伴生伪影（后文逐一给出对策）

| 伪影 | 机理 | 对策（章节） |
|---|---|---|
| **鬼影 ghosting** | 遮挡关系变化（disocclusion，先前被遮挡的区域变为可见），历史中保存的是已不存在的表面的颜色 | 邻域裁剪盒（§4.2）、速度自适应混合（§4.6） |
| **闪烁 flickering** | 成因有二：其一，邻域中的离群亮样本（outlier，指显著偏离样本主体的个别观测值，如镜面高光尖峰、噪点）会显著拓宽 minmax 盒，使历史值不再被有效裁剪，经混合留存十余帧；尖峰随高频信号反复出现时不断补充。其二，表面含亚像素级细节时，裁剪盒统计量随抖动逐帧漂移 | 方差盒（§4.2）、静止门控（§4.4） |
| **模糊 blurring** | 历史重采样与混合在本质上是低通滤波 | bicubic 历史重采样（§4.5）、感知空间混合（§4.7） |

## 2. 抖动采样（Jitter）

### 2.1 低差异序列与 Halton

抖动序列需满足两个条件：任意连续 $N$ 帧的偏移点集都**近似均匀地覆盖**像素单元（等效于 $N$ 点超采样）；相邻帧的位置差异大——历史混合的有效记忆窗有限（见 §4.6），超采样等效性主要由最近若干帧的抖动位置分布决定。伪随机序列仅在统计期望上均匀，任意具体的时间窗口内仍可能出现样本聚集或空缺；**低差异序列（QMC / 准随机序列）**则保证任意前缀点集的偏差（discrepancy）有界——即在任意时刻考察已累积的抖动位置集合，其分布都接近理想的超采样点集。

Halton 序列的每一维独立取不同基 $b$ 的**radical inverse（数字位镜像）**：

$$\phi_b(i)=\sum_{k=0}^{m-1} a_k\, b^{-(k+1)},\qquad\text{其中 } i=\sum_{k=0}^{m-1} a_k\, b^k$$

即将整数 $i$ 的 $b$ 进制各位倒序写到小数点后。二维点集取 $\big(\phi_2(i),\ \phi_3(i)\big)$（基 2 即 Van der Corput 序列）。实现即位循环：

```csharp
float result = 0, fraction = 1f / radix;
while (index > 0) { result += (index % radix) * fraction; index /= radix; fraction /= radix; }
```

实践要点：

- **帧索引避开 0**：$i=0$ 时位循环不执行、$\phi_b(0)=0$，抖动退化为固定角点 $(-0.5,-0.5)$；实测该固定相位会使对采样相位敏感的效果（如阴影贴图）出现可感知的不稳定（HDRP 源码注释即以此为由避开 0），故取 $(\mathrm{frame} \bmod 1024)+1$，形成 1024 帧周期；
- **偏移归中**：$j=\phi-0.5\in[-0.5,\,0.5)^2$，即亚像素幅度（最大半像素）；乘 `jitterScale` 可整体缩放幅度；
- **备选序列**：Jimenez（Filmic SMAA）推荐 R2 序列；HDRP 等使用 Halton(2,3)。二者目标性质一致。

### 2.2 把抖动注入投影矩阵的数学

像素偏移换算到 NDC：

$$t_x=j_x\cdot\frac{2}{W},\qquad t_y=j_y\cdot\frac{2}{H}$$

**方式一：裁剪空间齐次平移前乘** $\mathbf{P}_{jit}=\mathbf{T}(t_x,t_y,0)\,\mathbf{P}$：

$$\mathbf{T}=\begin{pmatrix}1&0&0&t_x\\0&1&0&t_y\\0&0&1&0\\0&0&0&1\end{pmatrix}$$

此处需注意齐次坐标的一个重要性质：**平移作用于齐次坐标时，随 $w$ 分量缩放**。设 $\mathbf{P}\mathbf{v}=(x_c,y_c,z_c,w_c)$，则

$$\mathbf{T}\,(\mathbf{P}\mathbf{v})=(x_c+t_x\,w_c,\ y_c+t_y\,w_c,\ z_c,\ w_c)$$

除以 $w_c$ 后：

$$\mathrm{NDC}'=\frac{x_c+t_x w_c}{w_c}=\mathrm{NDC}+t_x$$

即得到**与深度无关的常数屏幕偏移**——这正是抖动所需要的形式。若忽略该性质、误认为平移是"直接加在裁剪坐标上"，则会得出"偏移随深度变化"的错误结论。

**方式二：修改投影矩阵的偏斜分量 $m_{02}/m_{12}$**。OpenGL 风格透视投影满足 $w_c=-z_v$（行 3 为 $(0,0,-1,0)$），将 $x_c$ 加上 $\delta_x z_v$：

$$\mathrm{NDC}'=\frac{x_c+\delta_x z_v}{w_c}=\mathrm{NDC}-\delta_x$$

同样得到与深度无关的常数偏移。对同一抖动序列值 $\mathbf{j}$，两种方式的屏幕偏移**方向相反**（$+\mathbf{t}\equiv-\boldsymbol{\delta}$）、幅度精确相等，效果等价，可任选其一。但必须**全管线统一实现且帧间一致**：抖动投影常被跨帧缓存或重建（上一帧矩阵、重投影等），若不同的代码路径使用了符号相反的两种实现，重投影将产生相位不一致的错误。

### 2.3 抖动一致性规则（正确性的核心）

1. **深度与颜色同栅格**：抖动必须在相机矩阵推送之后、一切光栅化之前注入；若注入时机早于矩阵推送，抖动会被随后推送的矩阵覆盖而失效。深度与颜色在同一抖动投影下光栅化、逐像素对齐——后续所有依赖"深度与颜色对应关系"的操作（速度采样、遮挡判断）才有正确性基础。
2. **反投影同源**：将深度纹理还原为世界坐标时，必须使用**抖动投影的逆**（与深度的栅格同源）；若误用无抖动投影的逆，边缘像素会还原到错误的表面。
3. **速度无抖动**：运动矢量必须用**无抖动**的 VP 对计算。速度的语义是"帧间几何位移"——把当前帧像素中心映射回上一帧对应像素中心；它与"本帧采样相位"（抖动）是两个相互独立的量。resolve 在未抖动的 UV 网格上执行 $\mathbf{u}+\mathbf{v}$，故速度必须同样定义在未抖动空间；而抖动的相位差无需显式补偿——历史中每帧样本在采样时记录了当帧相位，多帧混合即等效于对这些相位的平均。
4. **全屏后处理不受抖动影响**：resolve 等全屏 pass 由顶点 ID 生成全屏三角、不经相机矩阵，其采样网格保持稳定的未抖动 UV。抖动只应作用于 3D 光栅化阶段，不应影响后处理的绘制几何。

## 3. 运动矢量与重投影

### 3.1 深度的线性化与反向 Z

设备深度 $d\in[0,1]$ 到线性视深 $z_{eye}$（透视投影，近、远裁剪面距离分别为 $n$ 与 $f$）：

$$\text{正向 Z（near}=0\text{，far}=1\text{）}:\quad z_{eye}=\frac{nf}{f-d\,(f-n)}$$

$$\text{反向 Z（near}=1\text{，far}=0\text{）}:\quad z_{eye}=\frac{nf}{d\,(f-n)+n}$$

**反向 Z 的动机**：设备深度 $d$ 是 $z$ 的双曲（$1/z$ 型）函数，而 float 的相对舍入精度在其指数范围内近似恒定。正向 Z 将远处的大段 $z$ 区间压缩到 $d\approx1$ 附近——那正是 $[0,1]$ 内绝对舍入间隔最大的位置，因此远处的深度判别误差急剧放大；反向 Z 将曲线翻转（近端 $d=1$、远端 $d\to0$），利用 float 在 0 附近指数密集的特性，使 $z$ 的相对重建误差在整个深度范围内近似均匀。"float 深度 + 反向 Z"由此成为现代管线的标准配置（经典分析：Nathan Reed, *Depth Precision Visualized*）。

由深度重建世界坐标（齐次反投影）：

$$\mathbf{p}_{world}=\mathbf{V}^{-1}\,\mathbf{P}_{jit}^{-1}\,\big(2u-1,\ 2v-1,\ z(d),\ 1\big)^{T}\quad(\text{结果除以 } w)$$

$\mathbf{V}$ 为视图矩阵，$z(d)$ 按平台深度约定（NDC z 范围与正/反向）取值；投影必须使用**抖动版本**（§2.3 规则 2）。工程上合并为一次 $\mathrm{InvVP}$ 变换。

### 3.2 相机运动矢量：全屏重建

对每个像素：由 $(uv, depth)$ 重建 $\mathbf{p}_{world}$，分别投影到上一帧与当前帧的 UV 空间：

$$\pi(\mathbf{p})=\frac{1}{2}\left(\frac{\big(\mathbf{VP}\,\mathbf{p}\big)_{xy}}{\big(\mathbf{VP}\,\mathbf{p}\big)_{w}}+1\right)$$

$$\mathbf{v}=\pi_{prev}(\mathbf{p})-\pi_{curr}(\mathbf{p})\qquad(\text{backward})$$

**符号约定与配对**：backward（$prev-curr$）将当前像素映射回上一帧位置，消费端直接使用 $\mathbf{u}_{hist}=\mathbf{u}+\mathbf{v}$；forward（$curr-prev$，URP 内置 MV 的约定）则须使用 $\mathbf{u}_{hist}=\mathbf{u}-\mathbf{v}$。**生成端的符号约定必须与消费端配对一致**——若符号接反，采样点将落在该表面点下一帧才会到达的位置（相当于向"未来"重投影），表现为拖影方向异常与鬼影加重。

- $\mathrm{UV}=\mathrm{NDC}\times0.5+0.5$，差分中常数项消去，故 NDC 速度 $\times0.5$ 恰为 UV 速度，存储值即 UV 空间速度；
- $y$ 分量在 `UNITY_UV_STARTS_AT_TOP` 平台（D3D/Metal）需翻转：NDC 的 $y$ 向上、屏幕纹理行序向下，两者相差一个镜像变换。

### 3.3 对象运动矢量

动态物体的几何在帧间发生位移，仅凭相机 MV 无法描述其运动，需要在对象级别计算 MV。对象 MV 在顶点着色器中同时输出两帧的裁剪坐标：

$$\mathbf{c}_{curr}=\mathbf{VP}_{curr}\,\mathbf{M}_{curr}\,\mathbf{v}_{os},\qquad \mathbf{c}_{prev}=\mathbf{VP}_{prev}\,\mathbf{M}_{prev}\,\mathbf{v}_{os}$$

片元着色器计算 $\pi(\mathbf{c}_{prev})-\pi(\mathbf{c}_{curr})$ 后写入同一张 MV 纹理。要点：

- **光栅位置与速度矩阵分离**：光栅化使用抖动投影（与深度/颜色同栅格），速度计算使用无抖动 VP 对——这是 §2.3 规则 1 与规则 3 在对象侧的体现；
- **遮挡剔除**：仅当片元是其像素处距相机最近的表面时，才应写入速度；否则遮挡边界处会记录到被遮挡表面的速度。做法：以**透视校正后的视深**比较场景深度与片元自身深度（避免裁剪空间 z 与深度纹理量纲不一致），执行 $\mathrm{clip}\big(z_{scene}-z_{frag}-\varepsilon\big)$——当表达式 $\le0$ 时片元被剔除；
- 对象 MV 依赖上一帧的模型矩阵 $\mathbf{M}_{prev}$（引擎侧逐对象缓存，或以全局矩阵提供单追踪对象）。

### 3.4 closest-depth 速度选点

在深度不连续处（轮廓线、物体交叠的深度断层），单点采样 MV 可能取到背景表面或前后景混合的速度。对策：在十字 5 点或 3×3 9 点邻域内比较深度，取**距相机最近的表面**所在的偏移位置采样 MV：

$$\mathbf{o}^{*}=\arg\min_{\mathbf{o}\in\text{邻域}}\ z_{eye}(\mathbf{u}+\mathbf{o})\qquad(\text{反向 Z 下即 } \arg\max\ d)$$

如此得到的速度属于最近表面，历史采样才能定位到上一帧的正确位置。该深度比较只需选点正确、无需高精度，half 精度足够：连续表面上即使选点略有出入，所取速度也几乎相同，视觉上无可察觉的差异；而在选点真正起作用的锐利深度边缘处，深度比较结果差异显著，half 精度足以可靠区分。

## 4. 历史混合（Resolve 核心）

每像素流程：**取当前帧样本 → 邻域统计 → 裁剪盒 → 选点取速度 → 重投影采历史 → 门控裁剪 → 确定混合系数 → 感知混合 → 输出**。

### 4.1 邻域统计：moment 单循环

对 3×3（或十字 5 点）邻域样本（已转换到工作空间，见 §5.1）在单次循环中累积：

$$\mu=\frac{1}{N}\sum_{i} c_i,\qquad \sigma^2=\frac{1}{N}\sum_{i} c_i^2-\mu^2,\qquad N\in\{5,9\}$$

同时维护由邻域样本最小值与最大值构成的边界 $\big[\min_i c_i,\ \max_i c_i\big]$（minmax 盒）。样本和 $\sum c_i$（moment1）与平方和 $\sum c_i^2$（moment2）在同一循环中计算得到；$\sigma$ 采用平方差公式，浮点误差可能使结果出现微小的负值，需以 $\max(0,\cdot)$ 或 $\mathrm{abs}$ 保护。

### 4.2 裁剪盒：minmax ∩ variance 双盒

- **minmax 盒**：由邻域样本的最小值与最大值直接构成的**确定性边界**。历史若落在该边界之外，大概率是失效样本（遮挡关系变化、历史中混入了其它表面的颜色），应按无效处理裁剪到盒内；其代价是真实但越界的渐变也会被截断——这是裁剪强度的本质代价；
- **方差盒**：$[\ \mu-\gamma\sigma,\ \mu+\gamma\sigma\ ]$，$\gamma\approx0.9$。其作用是排除邻域中的离群样本。当邻域中存在个别极端值（镜面高光尖峰、图像噪声）时，minmax 盒被显著拓宽，历史中的离群成分不再被有效裁剪，只能以混合的自然衰减速度存留（$\beta=0.1$ 时约十余帧），且尖峰随高频信号反复出现时不断补充——这是高光噪点闪烁的成因之一。方差盒以均值和标准差界定范围：个别极端值对 $\mu$ 与 $\sigma$ 的影响有限（9 个样本中的单个极端值 $B$ 仅使 $\mu$ 偏移约 $B/9$），故 $\mu\pm\gamma\sigma$ 的边界通常仍明显低于极端值本身；离群成分即使经混合短暂进入历史，也会在随后各帧被方差盒重新裁剪出去，无法长期存留。在平滑区域，$\sigma\to0$ 且 $\mu$ 稳定，盒收紧，将历史约束在稳定统计值附近，从而清除历史中累积的噪声。（当表面含亚像素级细节时，统计量本身随抖动逐帧漂移，该类闪烁由 §4.4 的静止门控处理。）

**双盒取交**：

$$\boxed{\ \mathbf{b}_{min}=\max\big(\min_{mm},\ \mu-\gamma\sigma\big),\qquad \mathbf{b}_{max}=\min\big(\max_{mm},\ \mu+\gamma\sigma\big)\ }$$

取交的数学意义：结果盒是两个盒的交集（$\min_{mm},\ \max_{mm}$ 为邻域 minmax 盒的边界）。无论方差统计如何波动，结果盒都不会比邻域的确定性边界（minmax）更宽，即统计噪声不会扩大裁剪范围。

$\gamma$ 控制裁剪的严格程度：$\gamma$ 调小时盒收紧，历史更快地被约束到当前帧统计附近，离群样本与残影被更快消除；但过强的裁剪会损失对比度与细节，并使输出跟随当前帧的噪声产生抖动。$\gamma$ 调大时历史受到的约束更弱、画面更平滑，但离群样本与残影的留存时间更长。

### 4.3 裁剪方式：clamp 与 clip-to-center

**逐通道 clamp**：$\mathrm{clamp}(h_j,\ b_{min,j},\ b_{max,j})$。计算最简单，但各通道独立拉回，合成后可能改变色相与饱和度结构（盒较紧时更明显）。

**clip-to-center（Playdead's TAA）**：将历史点沿"盒中心 → 历史"的方向拉回盒面。设盒中心 $\mathbf{c}$、盒半径 $\mathbf{e}$：

$$\mathbf{c}=\tfrac{1}{2}(\mathbf{b}_{max}+\mathbf{b}_{min}),\qquad \mathbf{e}=\tfrac{1}{2}(\mathbf{b}_{max}-\mathbf{b}_{min})$$

$$\mathbf{h}'=\mathbf{c}+\frac{\mathbf{h}-\mathbf{c}}{\max_j\left|\dfrac{h_j-c_j}{e_j}\right|}$$

（当 $e_j\to0$ 时须将其钳制到 $10^{-5}$ 量级以防除零。）该操作是保持"超出方向"不变的射线缩放，历史被拉回盒面时产生的色相失真显著小于逐通道 clamp；代价是若干次除法运算。

### 4.4 静止门控：闪烁的数学机理

裁剪盒的统计量来自**抖动后的当前帧**：当表面含亚像素级高频细节（细纹理、栅栏、文字）时，邻域采样点的位置随抖动逐帧变化，$\mu,\sigma,\min,\max$ 随之逐帧漂移——统计量本身即包含混叠噪声。若对所有帧恒定执行裁剪，历史值（经多帧混合已收敛到接近真实 box 积分的稳定值）在每帧都被拉向该漂移的裁剪盒，收敛值便在真值附近振荡——这是**静止画面闪烁**的一类根源（另一类成因是较宽的裁剪盒允许离群亮样本留存于历史，由 §4.2 的方差盒抑制）。门控规则：

$$\text{仅当 } \mathbf{v}\neq\mathbf{0} \text{ 时执行裁剪}$$

静止像素直接采用未经裁剪的历史值（由混合自身收敛），运动像素仍执行裁剪（以抑制鬼影）；关闭门控即退化为恒定裁剪。该门控依据像素的局部运动状态区别处理；增大 $\gamma$ 属于全局性调整，会同时削弱运动像素上的鬼影抑制，因此不能替代门控。

该门控的代价：在静态相机与静止背景下，遮挡物移开后新揭示的区域（disocclusion）速度为 0，其历史中的鬼影不再被即时裁剪，只能按混合系数的指数速度衰减（$\beta=0.1$ 时约十余帧才不明显）；而恒定裁剪可将此类鬼影在一两帧内截断。这是闪烁与拖影之间的工程取舍：门控以拖影衰减变慢为代价，换取静止画面无闪烁（URP 官方 TAA 即硬编码 $\mathrm{any}(\mathrm{velocity})$ 同款门控）；应按目标场景的静态/动态内容占比进行权衡。

### 4.5 历史重采样：bilinear 与 bicubic 5-tap

重投影采样点 $\mathbf{u}_{hist}=\mathbf{u}+\mathbf{v}$ 几乎从不落在像素中心，重采样质量决定历史清晰度。

**bicubic 5-tap（Jimenez 2016, Filmic SMAA）**：三次样条权重（$c=0.5$ 即 Catmull-Rom 族），$f$ 为采样点相对像素中心的分数位置：

$$w_0=-c f^3+2c f^2-cf,\quad w_1=(2-c)f^3-(3-c)f^2+1$$

$$w_2=-(2-c)f^3+(3-2c)f^2+cf,\quad w_3=c f^3-c f^2$$

标准双三次插值是两轴权重的 4×4=16 tap 外积 $\sum_{i,j}w_i w_j\,s_{ij}$。记 $w_{12}=w_1+w_2$：丢弃四个角点项（形如 $w_0 w_0$），并以 $w_{12}$ 合并中位采样位置，即可将采样简化为十字形的 5 个点：

$$h=\frac{\sum_k \omega_k\, s_k}{\sum_k \omega_k},\qquad (\omega_k)\in\{w_{12x}w_{0y},\ w_{0x}w_{12y},\ w_{12x}w_{12y},\ w_{3x}w_{12y},\ w_{12x}w_{3y}\}$$

丢弃角点后，各权重之和不再精确等于 1，因此必须显式除以 $\sum_k\omega_k$ 归一化（下标 $x/y$ 表示该权重沿哪一采样轴取值）。该方法以 5 次纹理采样获得接近完整 bicubic 的插值质量，历史混合后边缘明显更锐（对抗 TAA 低通特性造成的模糊）。

较低档位使用 bilinear。出界的历史不在重采样阶段处理，而在混合阶段以 $\beta=1$ 应对（见 §4.6）。

### 4.6 混合系数与记忆窗

基础混合：

$$h_n=(1-\beta)\,h_{n-1}+\beta\, c_n,\qquad \beta_0\approx0.1$$

不计裁剪的理想情形下可展开为几何级数——任一当前样本对后续输出的贡献为 $\beta(1-\beta)^k$，随帧数指数衰减：

$$h_n=\sum_{k=0}^{\infty}\beta(1-\beta)^k\,c_{n-k},\qquad \text{有效记忆窗}\approx\frac{1-\beta}{\beta}\approx 9\ \text{帧}\ (\beta=0.1)$$

**速度自适应混合（抑制鬼影）**：像素速度越大，历史值的可信度越低（重投影误差随速度增大），因此使混合系数随像素速度增大：

$$\beta=\mathrm{sat}\big(\beta_0+\|\mathbf{v}\|_{px}\cdot s\big),\qquad \|\mathbf{v}\|_{px}=\big\|\mathbf{v}\odot(W,H)\big\|,\quad s\approx0.02$$

其中 $\odot$ 为逐分量相乘：速度的 UV 两分量分别乘以屏幕宽、高后取模，即以像素计的速度长度。例如 $s=0.02$ 时速度 5 px 得 $\beta\approx0.2$；速度 50 px 时 $\beta$ 饱和为 1，即完全采用当前帧，历史中的残留立即被清除；速度为 0 时退回 $\beta_0$，保留 90% 历史权重的收敛收益。

**出界丢弃**：当 $\mathbf{u}_{hist}$ 位于 $[0,1]^2$ 之外时，历史采样必然无效——Clamp 寻址下采样会重复边缘像素。判定：

$$\mathrm{OOB}=\big|\mathbf{u}+\mathbf{v}-\tfrac{1}{2}\big|>\tfrac{1}{2}\ (\text{任一分量})\ \Longleftrightarrow\ \mathbf{u}_{hist}\notin[0,1]^2$$

触发时令 $\beta=1$。是否执行该检查可按档位取舍：bilinear 配合 Clamp 寻址在视觉上可部分掩盖出界误差，因此最低档位可省略此检查。

### 4.7 感知空间 lerp

人眼对亮度的敏感度近似对数（Weber–Fechner 律：可感知差异正比于相对变化 $\Delta L/L$）。在线性 HDR 空间直接执行线性插值时，高亮像素的绝对误差在视觉上被放大。HDRP 采用的做法是：将工作空间颜色除以其亮度加一所得的值，在近似感知域中混合后再还原：

$$\mathbf{w}=\frac{\mathbf{c}}{L(\mathbf{c})+1},\qquad \mathbf{c}'=\mathbf{w}\,\big(L(\mathbf{w})+1\big)$$

还原是**精确逆**（非近似）：

$$L\!\left(\frac{\mathbf{c}}{L+1}\right)=\frac{L}{L+1}\ \Rightarrow\ 1-L(\mathbf{w})=\frac{1}{L+1}\ \Rightarrow\ \mathbf{w}\,\big(L(\mathbf{w})+1\big)=\mathbf{c}$$

效果：插值发生在亮度归一化的近似感知域——亮色在混合前被压缩、混合后还原，混合残差按视觉敏感度随亮度缩放，各亮度区域的收敛在视觉上更均匀，对渐变与高亮区的色偏抑制更好。

数值注意事项：还原公式中的分母 $1-L(\mathbf{w})$ 随 $L$ 增大趋于零。$L(\mathbf{w})$ 接近 1，而 fp16 在 $[0.5,1)$ 区间的可表示值间隔为 $2^{-11}\approx4.9\times10^{-4}$，因此 $1-L(\mathbf{w})$ 的 half 计算结果只能落在 $2^{-11}$ 的整数倍上：$L\approx2000$ 时分母真值 $\approx5\times10^{-4}$，被舍入到 $2^{-11}$，还原产生约 2% 的偏差；随 $L$ 增大偏差急剧恶化（$L=3000$ 时已接近一半）；$L\gtrsim4095$（即 $1-L(\mathbf{w})<2^{-12}$）时，$L(\mathbf{w})$ 被舍入为 1，分母恰为 0，$\mathrm{rcp}(0)$ 产生无穷大。线性 HDR 的极端亮度场景需以 float 计算，或对 $L$ 设置上限保护。

### 4.8 当前帧滤波：抖动感知的 3×3 加权

最高质量档位可对**当前帧样本**额外执行 3×3 加权（源自 HDRP 的传统做法；其源码注释称为 Blackman-Harris 滤波，实际实现为高斯核）：

$$w_i=\frac{\exp\!\left(-\dfrac{d_i^2}{2\sigma^2}\right)}{\sum_j\exp\!\left(-\dfrac{d_j^2}{2\sigma^2}\right)},\qquad \sigma^2=0.22,\qquad d_i=\|\mathbf{o}_i-\mathbf{j}\|$$

$\mathbf{o}_i$ 为 3×3 整数偏移，$\mathbf{j}$ 为**本帧抖动**——距离以**未抖动像素中心**为参考点，抖动偏向哪个邻点，该点的权重越大。其作用是利用抖动帧的邻域样本，加权估计未抖动采样位置上的理想样本值（近似像素的 box 积分），在单帧内完成一部分相位重建，从而加速历史累积的收敛。权重由 CPU 逐帧计算后下发（9 个标量），GPU 侧只需做点积。

### 4.9 历史失效与重置

三类事件必须丢弃历史（以当前帧颜色初始化 $h_0=c_0$，跳过 resolve）：

1. **缓冲重分配**：尺寸或格式变化（含首帧），历史内容与新网格不对齐；
2. **camera cut**：首帧、相机实例切换、单帧大位移（判据如 $\|\Delta\mathbf{p}\|^2>f^2/4$）——此时速度不再有效，历史对应切换前的视角，与当前帧缺乏连续性；同时执行 $\mathbf{VP}_{prev}\!\leftarrow\!\mathbf{VP}_{curr}$，使速度归零；
3. **出屏重投影**：逐像素局部处理（$\beta=1$），不做整帧重置。

重置信号宜采用"**读取后立即清除**"的一次性语义，且必须无条件读取：若写成 `A || Consume()` 这类短路表达式，当 A 为真时消费被跳过、事件未被清除，下一帧将被再次读取——一次事件引发两次重置。

## 5. 颜色空间与数值精度

### 5.1 YCoCg 工作空间

盒的构建与裁剪按各颜色通道独立进行。自然图像的 RGB 通道强相关（$R\approx G\approx B$），轴对齐盒对斜向分布存在体积浪费——盒可能过紧（将合法颜色裁剪掉）或过松（允许鬼影存留）。YCoCg 去相关后能量集中于亮度轴：

$$\begin{pmatrix}Y\\C_o\\C_g\end{pmatrix}=\begin{pmatrix}\tfrac14&\tfrac12&\tfrac14\\[2pt]\tfrac12&0&-\tfrac12\\[2pt]-\tfrac14&\tfrac12&-\tfrac14\end{pmatrix}\begin{pmatrix}R\\G\\B\end{pmatrix},\qquad\begin{pmatrix}R\\G\\B\end{pmatrix}=\begin{pmatrix}1&1&-1\\1&0&1\\1&-1&-1\end{pmatrix}\begin{pmatrix}Y\\C_o\\C_g\end{pmatrix}$$

（Unity 实现给 $C_o,C_g$ 加 $128/255$ 偏置，平移到 $[0,1]$ 以适配无符号 8bit 缓冲；常数偏移使各通道统计整体平移，min/max 与方差的相对结构不变，裁剪语义等价，且往返精确。）

收益：

- 亮度 $Y$ 独占第 0 通道：亮度提取与感知加权无需额外计算；
- 去相关后轴对齐盒贴合实际分布、体积浪费小：亮度通道的误差被盒直接约束（人眼对亮度误差最敏感），色度按实际变化幅度裁剪；
- 人眼对色度误差的空间与时间敏感度均低于亮度（色度对比敏感度函数更低），落在色度通道的裁剪与混合残差在视觉上更不明显。较低档位可关闭 YCoCg 而使用 RGB，以裁剪质量换取两次矩阵乘法的计算量。

### 5.2 线性 HDR 与 gamma 空间近似

理想次序：**TAA 在线性 HDR（tonemap 之前）执行**——盒统计、方差、线性混合都保持在物理线性域，语义自洽。若在 tonemap 之后执行：高动态范围被非均匀压缩进窄区间，邻域统计与裁剪盒的有效分辨率被扭曲（高对比高光区的抗闪烁能力显著下降），且线性混合在非线性映射之后不再具有"平均"的数学含义。

工程上若只能在已编码的 gamma/LDR 缓冲上执行 resolve，进出工作空间时应做近似转换（gamma 2.0：输入时平方、输出时开方；相比 2.2 次幂计算成本更低，用于统计目的已足够）。转换必须**严格互逆**，并对历史、当前帧、全部邻域样本**一致应用**，否则盒统计与混合会产生系统性偏差。

### 5.3 half 精度知识

- fp16 范围上限 $65504\approx2^{16}$，最小规格化数 $\approx6.1\times10^{-5}$；绝对舍入间隔随幅度增长（约为幅度的 $2^{-11}$）——**数值范围与数值精度是两类不同的问题**；
- **moment2 溢出**：$\sum_i c_i^2$ 是 9 个样本的平方和，$9c^2>65504\Rightarrow c\gtrsim85.3$。线性 HDR 下天空与高光的亮度轻易超过此值——half 累加器在亮部发生数值溢出而不产生任何错误信息，$\sigma^2$ 的计算随之失效，方差盒在亮部失去作用（鬼影与闪烁重新出现）。对策：仅将**累加路径**（平方和、均值、$\sigma$ 及其派生量）提升到 float；盒的 min/max 是 half 样本的逐通道比较、不含累积故不会溢出，可保持 half——即范围问题只需在累加处解决，采样与比较无需全部采用 float；
- closest-depth 比较采用 half 精度足够（理由见 §3.4）；
- 抖动偏移的量级为 $2/W\sim10^{-3}$，相关矩阵的构造须在 CPU 侧以 float 精度完成。

## 6. 质量分档的设计逻辑

TAA 有四条正交质量轴与一个颜色空间开关，各轴的成本与收益相互独立：

| 轴 | 取值 | 成本 | 主要收益 |
|---|---|---|---|
| clampMode | 十字5 minmax → 3×3 minmax → minmax∩variance → +clip-to-center | 盒构建采样数 / 裁剪 ALU | 离群值抑制↔保真平衡 |
| motionTaps | 0 / 5 / 9 closest-depth | 深度采样次数 | 边缘速度正确性 |
| historyMode | bilinear / +出界检查 / bicubic 5-tap | 1 / 1 / 5 tap | 历史锐度 |
| filterCurrent | point / 3×3 滤波 | 1 / 9 tap | 当前帧亚像素重建 |
| YCoCg | on / off | 2 次矩阵乘 | 裁剪盒质量 |

典型五档组合（URP/HDRP 传统分档，低档→高档单调增强）：

| 档位 | clamp | motion taps | history | 当前帧滤波 | 颜色空间 |
|---|---|---|---|---|---|
| Very Low | Cross5 | 0 | bilinear | ✗ | RGB |
| Low | Cross5 | 5 | bilinear + OOB | ✗ | RGB |
| Medium | Dual 3×3 | 9 | bilinear + OOB | ✗ | YCoCg |
| High | Dual 3×3 | 9 | bicubic | ✗ | YCoCg |
| Very High | Dual + clip-to-center | 9 | bicubic | 3×3 加权 | YCoCg |

**分档的实现形态是三个工程方案的取舍**：

1. **shader_feature 关键字**：各轴取值构成笛卡尔积组合（如 4×3×3×2×2 = 144 个潜在组合），全部使用关键字将导致变体数量按笛卡尔积增长；且存在**打包裁剪风险**——构建时未被场景引用的变体被剥离，运行时切换失效。这一类风险应整体规避；
2. **全 uniform 单 pass**：零变体、运行时可即时切换，但所有档位的分支指令全部编入，每个档位都要为其它档位的分支路径承担代码体积与寄存器开销；
3. **多 pass + 常量实参**：质量轴以函数字面实参（或 per-pass `#define`）传入核心函数，编译期常量传播可将 `if (mode>=2)` 类分支整体消除——**每个档位获得等同于手写专用代码的质量**，零变体、无裁剪风险，切换仅是更换 pass 索引（即时）。代价：着色器文件中的 pass 数量与维护成本。

运行时可调参数（静止门控、自适应混合开关、$\gamma$、$\beta_0$、感知混合开关）**不应**烘焙进档位——保留为每帧下发的 uniform，参数改动下一帧生效，且不触发任何重编译。

## 7. 知识点拾遗

- **乒乓历史缓冲**：双 RT 轮换读写，读取"上一帧的写入槽位"。resolve 不能原地读写同一纹理——同一 drawcall 内读写同一目标属未定义行为。
- **反向 Z 下的"最近表面"**：深度值最大即距相机最近（near=1）；closest-depth 选点与深度线性化都须按平台约定分支。
- **`UNITY_UV_STARTS_AT_TOP`**：D3D/Metal 的屏幕纹理行 0 位于顶部，而 NDC 的 $y$ 向上。凡在 NDC 位移与 UV 位移之间转换的场合（MV 生成、重投影）都需翻转 $y$；已处于 UV 空间的运算不再涉及。
- **速度在 UV 空间的量纲**：MV 纹理常用 half 双通道格式（R16G16），一般足以承载亚像素级精度的 UV 速度；自适应混合前须换算为像素速度（$\mathbf{v}$ 的两分量分别乘以 $W$、$H$ 后取模）。
- **camera cut 判据的保守性**：位移阈值取 $f/2$（远裁剪面一半）量级——正常移动的单帧位移远小于该阈值（不会误触发），瞬移/传送远大于该阈值（必然触发）。
- **收敛速度与拖影相互制约**：$\beta$ 小则记忆窗长，静止画面收敛平滑，但错误样本的留存时间也更久；$\beta$ 大则相反。速度自适应 $\beta$ 的实质是依据运动速度局部缩短记忆窗。
- **TAA 与 MSAA 的关系**：二者互补（每样本抖动 + 时序累积即 STAA），但叠加成本高；现代管线通常二选一。MSAA 管线下若执行 TAA，抖动需作用于每个样本位置。
- **透明物体**：对象 MV 通常只覆盖不透明队列，透明表面仅有相机 MV 可用，其自身运动不参与重投影——透明边缘是 TAA 鬼影与闪烁的常见残留位置。
- **后置锐化**：重采样与混合不可避免地轻度模糊输出，实践中常在 TAA 之后串联一次轻量锐化补偿；锐化必须在 TAA 输出上执行而不可置于历史反馈内，否则高频噪声会被逐帧累积放大。
- **renderScale / 动态分辨率**：颜色、深度、MV、历史四类纹理的子矩形一致性必须整体审计——管线层的缩放/偏移机制（如 `_BlitScaleBias`）只保证绘制几何落在正确的视口区域，着色器内的 texel 偏移、速度换算、重投影采样仍须逐一对齐。
- **XR stereo**：纹理声明与采样须双目数组化（`TEXTURE2D_X` 族），单目写法在双目 pass 下因缺少 array slice 索引而渲染错误。
- **工作空间转换的一致性**：进出工作空间（gamma 近似、YCoCg）的变换必须严格互逆，并一致应用于历史、当前帧与全部邻域样本；不对称或不一致的转换会使盒统计与混合产生系统性偏差（参见 §5.2）。
